## 1. Editorial Integrity & Evidence Classification

In strict adherence to the project audit rules:
- **Zero Fabricated Metrics:** No estimated monthly search volumes, keyword difficulty (KD) percentages, CPC values, or artificial rank positions are invented.
- **Evidence Level Distinction:** Every mapped query is explicitly classified into one of two evidence tiers:
  1. `[VERIFIED EVIDENCE]`: Query phrases directly observed in live search engine suggestions, publicly accessible developer documentation, or actual competitor tool titles, URLs, and H1 tags verified during competitor research.
  2. `[WORKING HYPOTHESIS]`: Inferred developer search queries or long-tail user workflow phrases based on tag technical semantics and intended user actions, but lacking independent third-party search volume verification.
