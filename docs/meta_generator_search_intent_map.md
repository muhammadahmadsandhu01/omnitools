## 3. Intent Architecture Decisions

1. **Single Canonical Authority:**
   All overlapping tag generation intents (`meta tag generator`, `open graph generator`, `twitter card generator`, `social preview tool`, `meta robots generator`) are consolidated onto the single canonical route `/seo/meta-generator`. Alias routes (`/seo/meta-tags-generator` and `/seo/open-graph-generator`) map directly to the same component and are redirected cleanly to prevent keyword cannibalization and thin duplicate doorway pages.

2. **Distinct Auditor & Generator Duality:**
   Rather than splitting creation and inspection into separate fragmented tools, OmniTools provides both in a unified two-tab interface:
   - **Editor Tab:** For crafting new metadata from scratch or presets.
   - **Auditor Tab:** For pasting existing HTML head snippets or inspecting public URLs to audit compliance and import into the editor.

3. **Natural Linguistic Integration:**
   Headings, guides, and FAQs address core real-world developer problems (image sizing, pixel truncation, canonical requirements, robots pitfalls) with zero keyword stuffing or robotic repetition.
