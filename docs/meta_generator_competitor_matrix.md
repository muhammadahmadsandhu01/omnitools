---

## 1. Research Methodology & Evidence Scope (Mandatory Clarification)

To avoid overstating verification depth, the evidence behind each entry in this matrix is classified into four distinct levels:

1. **Automated HTTP Probe & Page Content Inspection:** An automated HTTP request (`scratch/probe-meta-competitors.mjs`) verified HTTP status, payload size, redirected destination, and response headers. The returned HTML was inspected for form fields, layout structure, and script dependencies.
2. **Interactive Browser Testing:** Hands-on interaction was executed where form fields were typed into and live preview/output updates were directly observed in a browser session. This was conducted for OmniTools and selected open direct tools (e.g., MetaTags.io).
3. **CMS / Platform Documentation Review:** For products requiring a WordPress environment (Yoast, Rank Math, AIOSEO) or paid enterprise subscriptions ($99+/mo for Ahrefs, Semrush), verification was performed by analyzing official documentation, feature specification pages, and public marketing material.
4. **Official Technical Reference:** Sites that are formal standard specifications (Google Search Central, OGP, X Developer Docs, Schema.org) contain no interactive generators. They are included as normative benchmarks for semantic accuracy and attribute naming.
