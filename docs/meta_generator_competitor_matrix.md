## 2. Competitive Insights & OmniTools Opportunity Gap

### What Users Reasonably Expect
1. **Immediate Execution:** Instant generation of `<head>` tags without registration, paywalls, or newsletter modals.
2. **Multi-Platform Previews:** High-fidelity simulations of how cards appear on Google (desktop & mobile), Facebook, Twitter/X, and LinkedIn.
3. **Smart Synchronization:** Automatic inheritance of social titles and descriptions from base SEO fields to avoid repetitive retyping, paired with the freedom to override them.
4. **Clean Code Generation:** Properly escaped HTML attributes (`&quot;`, `&amp;`, `&lt;`, `&gt;`, `&#39;`) with zero leftover template placeholders.
5. **Clear Copy & Export:** One-click copy for all tags or filtered sections (Basic SEO only, Open Graph only, Twitter only), plus `.html` file download.

### Genuine Architectural Differentiators Solved by OmniTools
1. **Pasted-HTML & Live URL Auditor:** Unlike basic form-only generators, OmniTools includes a built-in Auditor that parses existing HTML head code or queries public URLs with SSRF defense, scores it 0–100, and allows one-click import into the editor.
2. **Proactive Validation & Guidance:** Inline warnings for insecure HTTP canonicals, missing social images, and relative URLs, plus character and approximate pixel-width guides.
3. **Decoupled Social Overrides:** When social synchronization is disabled, empty social overrides stay cleanly omitted instead of outputting confusing empty or dummy tags.
4. **Strict Zero-Upload Client-Side Privacy:** Form generation runs 100% in browser memory with zero tracking scripts, zero telemetry, and zero draft transmission.
5. **Safe Scriptless Parsing:** Pasted HTML in the auditor is parsed using browser DOMParser without executing embedded scripts or third-party iframes.
